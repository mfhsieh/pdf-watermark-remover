## 📌 專案簡介

本專案基於 `pdf-lib` 程式庫，在瀏覽器端直接解析與修改 PDF 的內容與結構。此工具並非將 PDF 轉換為圖片擦除，而是嘗試在底層結構中清除浮水印物件，因此能保留原始文件的向量字型、清晰度與可複製文字。所有處理皆在本機端完成，無須擔憂敏感資料外流。

## 💡 主要功能

### 1. 多元特徵比對（關鍵字、巨型文字、高透明度、高頻）
為了解決各種浮水印變體，系統在「全域設定」中提供五種自動判定機制：
- **資源鍵名與圖層名稱關鍵字**：用於比對表單、影像、延伸圖形狀態或圖層的內部資源名稱（建議輸入英文或簡寫）。
- **「頁面直接內容」關鍵字與雙編碼匹配**：用於比對直接寫入於內容串流中的文字。非 ASCII 字元會自動編譯為 **UTF-16BE** 位元組特徵碼；中文字元則額外產生 **Big5** 位元組特徵碼，大幅提高對台灣舊式系統的命中率。
- **巨型文字特徵門檻 (字型大小)**：針對「巨型文字區塊 (TextBlocks)」設計。當文字的實際顯示大小大於或等於此數值時，系統即會將其預選。
- **高透明度特徵門檻**：針對「延伸圖形狀態 (ExtGState)」設計。當物件較透明 (alpha 值較小) 時，系統即會將其預選。
- **高頻特徵門檻**：針對「表單外部物件 (Form XObject)」與「影像外部物件 (Image XObject)」設計。當同一物件出現頻率較高時，系統即會將其預選。
- **限制**：部分 PDF 在產生或轉存時會對文字進行重新編碼（如轉為字型子集 (Font Subset)、自訂字元對應表 (CMap)，或將文字轉為向量路徑），此情況下字元的位元組特徵與原始輸入不符，關鍵字比對將無法命中。建議善用「預覽」功能確認實際效果。

### 2. 七種清除策略可分別勾選
針對 PDF 底層結構的七種物件類型，支援個別偵測、預覽與勾選：
- **表單外部物件 (Form XObject)**：獨立封裝的複用元件（支援深層巢狀結構掃描），常見於整頁重複疊加的背景或滿版浮水印。
- **影像外部物件 (Image XObject)**：以點陣圖（如 JPEG、PNG）形式存在的浮水印，如公司 Logo、章戳或掃描背景。
- **註解 (Annotation)**：包含浮水印 (Watermark)、蓋印與圖章 (Stamp) 等附加於頁面上方的互動元件。
- **頁面直接內容 (Direct Content)**：直接寫入於頁面內容串流 (Content Stream) 中的文字型浮水印（如「機密」、「限閱」），支援雙編碼匹配。
- **巨型文字區塊 (TextBlocks)**：透過精確計算版面座標轉換矩陣 (CTM 與 Tm)，自動偵測並清除不尋常大小的巨型文字浮水印。
- **選擇性內容群組 (Optional Content Group, OCG)**：可控制特定背景或浮水印可見性的圖層。
- **延伸圖形狀態 (ExtGState)**：控制透明度（Alpha 值）與混合模式狀態的物件，常見於半透明背景或斜角文字浮水印。

### 3. 預覽功能（個體標記 + 雙欄前後對照）
清除前可先確認效果，降低誤刪的風險：
- **個體預覽**：點擊項目旁的「預覽」，系統會產生隔離該物件的 PDF，部分不可視物件會以**半透明紅框（支援累積變換矩陣 CTM 精確解析，還原傾斜與縮放角度）**標示其位置。
- **雙欄前後對照**：處理完成後，可在主畫面左右比較清除前後的差異。

### 4. 權限解鎖與密碼沿用
- **自動解除編輯限制**：無開啟密碼 (User Password) 但限制編輯、複製、列印的 PDF，系統會自動在背景解除限制。
- **密碼驗證與跨檔案沿用**：若文件設有開啟密碼，會彈窗詢問。驗證成功後的密碼暫存於記憶體（不落地儲存），接續處理密碼相同的檔案時可自動套用。

### 5. 資安防護與效能優化
- **純前端架構與 CSP 防護**：檔案不經任何伺服器上傳，100% 於本地端處理。同時導入嚴格的內容安全策略 (CSP) 並全面禁用危險的 DOM 操作。
- **預覽記憶體釋放**：關閉預覽彈窗時立即執行 `URL.revokeObjectURL()`，避免頻繁預覽大型檔案造成記憶體積壓。
- **輸出檔案體積最佳化**：修改後的頁面內容串流 (Content Stream) 支援自動透過 `pako` 進行 Zlib/Deflate 重新壓縮，大幅減少輸出的 PDF 體積。
- **DOM 節點快取**：集中快取主要 DOM 節點，減少重複遍歷的效能耗損。

## 📖 如何使用

本工具的操作流程非常直覺，只需幾個簡單步驟即可完成浮水印的清除：

### 1. 上傳檔案與極速掃描
將 PDF 檔案拖曳或上傳後，系統會自動在背景執行極速掃描，並在下方展開「清理策略」面板。

### 2. 全域設定 (選項)
您可以在「選擇清除策略」旁的「📝」按鈕展開「全域設定」，根據檔案的實際狀況，手動微調上述的五種**關鍵字**與**判定門檻**。

### 3. 確認勾選七大策略及子項
- 系統掃描後，會為您**自動預先勾選**具有浮水印特徵的物件。
- 您可以點擊「⚙️」展開各個策略的子項清單，進行手動微調。例如：您可以選擇保留「打字機文字」的註解，但強制勾選刪除特定的「表單外部物件」。

### 4. 針對單一物件「預覽」
為了避免誤刪重要的正文圖表，在各策略的子項設定清單中，您可以針對任何有疑慮的物件點擊 **「👁️」 (預覽)** 按鈕。
系統會即時產生該物件的單獨視窗預覽（若是不可視的物件，則會精準計算變換矩陣，以半透明多邊形紅框高亮標示其位置與旋轉角度），讓您百分之百確認該物件是否為惱人的浮水印。

### 5. 執行清除
確認勾選狀態無誤後，點擊畫面中央的 **「開始清除浮水印」** 按鈕。系統會在瀏覽器記憶體中，以「無損置換」的技術安全地剝離浮水印底層結構，不會破壞原始文件內容。

### 6. 雙欄對照與下載
處理完成後，頁面下方會出現**雙欄前後對照區**。您可以即時在左方（原始文件）與右方（清除後文件）滑動比對。確認清除效果達到預期後，點擊出現的 **「下載處理後 PDF」** 即可將乾淨的檔案存回您的電腦中。

## 🚀 離線使用

本專案為**純前端靜態網頁工具 (Client-Side Static Tool)**，不依賴後端伺服器；首次使用載入並快取核心程式庫後，即可離線使用：
- **下載與執行**：您可以直接下載專案提供的壓縮檔（或在終端機執行 `npm run build`，也可直接執行 `./bin/build-zip.sh` 來打包離線版本）。解壓縮後，在任何現代瀏覽器中雙擊打開 `index.html` 即可執行，無需安裝伺服器環境。
- **離線運作**：首次開啟工具時，請確保有網路連線，以便從 CDN 載入並快取核心程式庫（包含 `pdf-lib`、`text-encoding`、`pako` 以及解密用的 `qpdf-wasm` 引擎）。完成首次載入後，瀏覽器即可使用已快取的程式庫，在無網路環境下處理 PDF；若清除瀏覽器快取或更換瀏覽器，需重新連線載入程式庫。

## ⚠️ 免責聲明

開始使用前，請詳閱以下說明：

1. **重要文件請務必備份**：雖然預覽功能可降低誤刪風險，但清除浮水印涉及修改 PDF 原始結構，請務必保留原始檔案備份。
2. **技術與相容性限制**：PDF 格式較為複雜，若文件採用特殊字型子集 (Font Subset)、自訂字元對應表 (CMap) 或文字轉向量路徑，關鍵字可能無法命中，請善用預覽功能確認效果。
3. **法律責任**：本工具在本地端處理，不會收集您的文件。請確保您擁有清除浮水印的合法權利（如個人學習、合理使用或已獲授權），相關版權與法律責任由使用者自行承擔。
