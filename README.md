## 📌 專案簡介

本專案透過 `pdf-lib` 程式庫直接在瀏覽器記憶體中重構 PDF 檔案，所有處理皆在本機端完成，**檔案絕對不會上傳至任何後端伺服器**，能有效保障文件隱私。

## 💡 主要功能

### 1. 六種清理策略
工具提供以下六種常見 PDF 物件的掃描與清理選項：
- **移除背景浮水印 (Form XObject)**：移除封裝在獨立子畫布中的向量或文字型浮水印，為最常見的浮水印格式。
- **移除疊加註解 (Annots)**：移除覆蓋在文件上層的 PDF 標記、電子印章或附註型浮水印。
- **掃描並清除嵌入內容 (Direct Content)**：若浮水印直接寫入頁面內容流，可透過自訂的關鍵字比對並清除命中內容。
- **清理半透明效果 (ExtGState)**：清除透明度設定中與浮水印相關的 ExtGState 物件，並可透過自訂關鍵字比對名稱進行精準過濾。
- **清除浮水印圖層 (OCG)**：若浮水印定義在特定的選用內容圖層（Optional Content Group）中，可透過自訂關鍵字比對圖層名稱並將其失效。
- **移除圖片型浮水印 (Image XObject)**：若浮水印為圖片形式，可透過自訂命名關鍵字比對 XObject 名稱並予以清除。

### 2. 雙欄對照預覽（Before & After）

提供「Before & After 雙欄對照預覽」，方便在下載前確認浮水印移除前後的視覺差異。

### 3. 精準解鎖「檔案權限限制」與「開啟密碼限制」

工具會自動偵測並分析 PDF 文件的加密保護狀態：

- **檔案權限限制**（無開啟密碼，但限制列印、編輯與複製等）：系統會自動導入 `qpdf-wasm` 進行權限解除，無須使用者手動介入，過程快速且自動化。
- **開啟密碼限制**（設有開檔密碼保護）：系統會主動識別並彈出密碼輸入框，由使用者輸入密碼後完成解密與浮水印清理。

### 4. 自訂過濾關鍵字與進階比對模式（持久化儲存）

為避免在清理浮水印的過程中誤刪正常的文件內容或圖片，工具針對核心功能提供了四大類別的自訂過濾關鍵字。

所有自訂設定都會自動安全地儲存在瀏覽器的 `localStorage` 中，即使重新整理網頁或下次開啟，也無須重新輸入。

為了滿足不同複雜度的 PDF 文件清理需求，工具提供了以下三種**進階匹配模式**（每項清理策略皆可於設定視窗中獨立設定，且設定會自動持久化儲存）：

*   **預設模式（子字串包含 / Includes）**：
    *   **機制**：只要 PDF 內部物件名稱或內容流文字中「包含」任何關鍵字即判定為命中（不分大小寫）。
    *   **場景**：最通用，適合大範圍搜尋與一般快速清理。
*   **精確完全匹配 (Exact Match)**：
    *   **機制**：PDF 內部物件名稱必須「完全等於」某個關鍵字時才命中（不分大小寫）。
    *   **場景**：適合用於**防範誤刪正常圖片或透明參數**。例如當文件包含正常的圖片 `/Image1`，而浮水印圖片命名為 `/wm`，勾選精確匹配並輸入 `wm` 時，將能精準移除 `/wm` 而絕對不會誤傷 `/Image1`。
*   **正規表示式匹配 (Regex Match)**：
    *   **機制**：將輸入的每一行或逗號分隔項目視為「正規表示式（不分大小寫）」進行精準模式比對。
    *   **場景**：適合用於**匹配動態變動或序列化的浮水印物件名稱**（例如浮水印命名為 `/wm1`、`/wm2` 等，可直接輸入正規表示式 `wm\d+` 來一次清理），或對 Direct Content 流文字進行複雜比對。

#### 關鍵字策略分類與預設值：

- **掃描特徵關鍵字**（適用於：*掃描並清除嵌入內容*）
  - **預設值**：`watermark`, `wm`, `confidential`, `draft`, `sample`, `internal`, `copy`, `trial`, `evaluation`, `demo`, `機密`, `內部`, `草稿`, `樣本`, `樣品`, `複製品`, `浮水印`, `水印`, `僅供參考`
  - **作用**：於頁面內容流（Direct Content）中，搜尋是否有寫死在文字繪製指令中的明文浮水印特徵字串。
- **圖片命名關鍵字**（適用於：*移除圖片型浮水印*）
  - **預設值**：`watermark`, `wm`, `stamp`, `logo`, `bg`, `background`, `sign`, `signature`, `shuiyin`
  - **作用**：比對 PDF 內部資源樹中 Image XObject 的物件名稱（例如 `/Watermark1`、`/wm2` 等），可有效避免誤刪正常的插圖與照片。
- **ExtGState 關鍵字**（適用於：*清理半透明效果*）
  - **預設值**：`watermark`, `wm`, `trans`, `opacity`, `gs`, `alpha`, `blend`, `adbe`, `adobe`
  - **作用**：有些浮水印會透過半透明資源狀態（ExtGState）控制其透明度，通常這些狀態名稱會包含特定關鍵字（如 `/TransWM`），比對可精準重置該透明參數，而不影響正常頁面的透明設定。
- **OCG 關鍵字**（適用於：*清除浮水印圖層*）
  - **預設值**：`watermark`, `wm`, `layer`, `stamp`, `print`, `overlay`, `shuiyin`, `浮水印`, `水印`
  - **作用**：比對 Optional Content Group（可選內容圖層）的名稱，只讓包含關鍵字的圖層（例如名稱為 "Watermark Layer" 的圖層）失效，保留其他正常的製圖或圖表圖層。

## 🚀 離線使用與可攜性

本專案採用 **「單頁應用程式 (SPA)」** 架構，所有 CSS 樣式與 JavaScript 邏輯皆內嵌於單一 `index.html` 中，具備良好的可攜性：

- **直接開啟**：在檔案總管中雙擊 `index.html`，即可在任何現代瀏覽器（Chrome, Edge, Firefox, Safari 等）中執行。
- **便於傳播**：可將此單一 HTML 檔案發送給同事或儲存在隨身碟中。
- **離線限制**：處理無加密 PDF 時可完全離線運作；若需解除密碼或權限限制，首次使用時需連線以下載 `qpdf-wasm` 引擎（約 1.8 MB），之後由瀏覽器快取。

## ⚠️ 免責聲明

開始使用前，請詳閱以下說明：

1. **相容性限制**：由於各 PDF 文件之製作規格與標準不同，本工具無法保證適用於所有檔案，部分加密或特殊排版之文件可能無法完整處理。

2. **備份原始檔案**：移除浮水印會修改 PDF 內部結構，處理前請先備份原始檔案，以避免資料遺失。

3. **合法使用授權**：請確認您擁有該文件移除浮水印之合法權利（例如個人學習、合理使用或已取得原作者之授權）。若因移除浮水印衍生任何版權爭議或法律責任，均須由使用者自行承擔。
