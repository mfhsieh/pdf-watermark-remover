## 📌 專案簡介

本專案透過 `pdf-lib` 程式庫直接在瀏覽器記憶體中重構 PDF 檔案，所有處理皆在本機端完成，**檔案絕對不會上傳至任何後端伺服器**，能有效保障文件隱私。

## 💡 主要功能

### 1. 六種清理策略 (全新六大 Modal 精確個體勾選)
工具提供以下六種 PDF 物件的高速偵測與清理選項。現在，六種清理策略均已 100% 升級為**「個體實例精確勾選過濾」**模式，工具會在背景自動解析上傳檔案的具體結構，將實際偵測到的實例動態呈現在專屬設定 Modal 中，供使用者直觀、自主勾選需要清除的特定實體，徹底杜絕因關鍵字模糊匹配可能誤殺正常正文、插圖或渲染效果的風險，實現全方位的安全防誤殺：
- **移除表單外部物件 (Form XObject)**：提供**「表單外部物件精確勾選」**設定彈窗，偵測並列出 PDF 每一頁中的 Form XObject（向量或文字型背景物件）實例並標記頁碼與解碼文字內容，預設自動預勾選疑似浮水印的背景物件，其餘安全保留。
- **移除註解 (Annotation)**：提供**「註解個體精確勾選」**設定彈窗，列出 PDF 中每一個具體的註解實例並標記所在頁碼與解碼文字內容，允許自由勾選要清除的個別實例，並預設自動預勾選最常作為浮水印的 `Watermark`（浮水印）與 `Stamp`（圖章），同時保留「超連結」等其他註解不被破壞。
- **掃描並清除頁面直接內容 (Direct Content)**：提供**「頁面直接內容精確勾選」**設定彈窗，偵測並列出 PDF 每一頁中的頁面直接內容（Content Stream）實例並標記頁碼與解碼文字內容，允許自由勾選要清除的個別頁面直接內容實例（預設自動預勾選疑似浮水印的串流），能最大程度地防止誤刪整頁正常正文。
- **清理延伸圖形狀態 (ExtGState)**：提供**「延伸圖形狀態精確勾選」**設定彈窗，偵測並列出每一頁 Resources 中的延伸圖形狀態，獲取非描邊透明度 `/ca`、描邊透明度 `/CA` 以及混合模式 `/BM` 等特徵作為預覽文字，預設自動預勾選疑似浮水印的半透明設定（如透明度低於 0.5）。
- **清除選擇性內容群組 (OCG)**：提供**「選擇性內容群組精確勾選」**設定彈窗，偵測並列出全域的 OCG 圖層名稱明文，允許自由勾選要隱藏的特定圖層（預設自動預勾選名稱疑似浮水印的圖層）。
- **移除影像外部物件 (Image XObject)**：提供**「影像外部物件精確勾選」**設定彈窗，偵測並列出 PDF 每一頁的影像實例，並清晰提供寬高尺寸（例如 `800x600`）與壓縮濾鏡格式（例如 `DCTDecode`）等特徵作為預覽文字，方便使用者精確勾選要清除的圖片型浮水印，而安全保留正常的插圖與 LOGO。

### 2. 雙欄對照預覽（Before & After）

提供「Before & After 雙欄對照預覽」，方便在下載前確認浮水印移除前後的視覺差異。

### 3. 精準解鎖「檔案權限限制」與「開啟密碼限制」

工具會自動偵測並分析 PDF 文件的加密保護狀態：

- **檔案權限限制**（無開啟密碼，但限制列印、編輯與複製等）：系統會自動導入 `qpdf-wasm` 進行權限解除，無須使用者手動介入，過程快速且自動化。
- **開啟密碼限制**（設有開檔密碼保護）：系統會主動識別並彈出密碼輸入框，由使用者輸入密碼後完成解密與浮水印清理。

### 4. 零模糊匹配，安全不誤殺

為了提供極致的安全保障，本專案完全廢除了所有舊有的模糊匹配關鍵字文字輸入框、正規表示式與精確比對選項，且完全不使用 `localStorage` 存取 any 敏感設定。現在所有的清除動作都嚴格地對齊 PDF 中的具體實體個體。

#### 疑似浮水印自動預打勾：
背景高速掃描時，會根據預設的疑似浮水印特徵（如名稱或內文含 `watermark`、`wm`、`logo`、`shuiyin` 等，或 ExtGState 含有特定的透明度/混合模式）**自動預先打勾**。使用者只需核對並點擊套用即可。

### 5. 密碼安全機制

*   **跨檔案密碼安全沿用**：前次成功解密的密碼暫存於運行期記憶體（不落地，禁止存入 `localStorage`）。新上傳加密 PDF 時會於背景自動嘗試解密，失敗時再行詢問。網頁重整或關閉後即自動徹底清除。

## 🚀 離線使用與可攜性

本專案採用 **「單頁應用程式 (SPA)」** 架構，所有 CSS 樣式與 JavaScript 邏輯皆內嵌於單一 `index.html` 中，具備良好的可攜性：

- **直接開啟**：在檔案總管中雙擊 `index.html`，即可在任何現代瀏覽器（Chrome, Edge, Firefox, Safari 等）中執行。
- **便於傳播**：可將此單一 HTML 檔案發送給同事或儲存在隨身碟中。
- **離線限制**：處理無加密 PDF 時可完全離線運作；若需解除密碼或權限限制，首次使用時需連線以下載 `qpdf-wasm` 引擎（約 1.8 MB），之後由瀏覽器快取。

## ⚠️ 免責聲明

開始使用前，請詳閱以下說明：

1. **相容性限制**：由於各 PDF 文件之製作規格與標準不同，本工具無法保證適用於所有檔案，部分加密或特殊排版之文件可能無法完整處理。

2. **備份原始檔案**：移除浮水印會修改 PDF 內部結構，處理前請先備份原始檔案，以避免資料遺失。

3. **合法使用授權**：請確認您擁有該文件移除浮水印之合法權利（例如個人學習、合理使用或已取得原作者之授權）。若因移除浮水印衍生任何版權爭議或法律責任，均須由使用者自行承擔。
