# 純前端 PDF 浮水印移除工具 [![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](https://github.com/mfhsieh/pdf-watermark-remover/)

這是一個輕量、免安裝且 100% 在本機瀏覽器端執行的 [純前端 PDF 浮水印移除工具](https://mfhsieh.github.io/pdf-watermark-remover/)。

## 📌 專案簡介

本專案採用純前端靜態解析技術，透過 `pdf-lib` 庫直接在瀏覽器記憶體中重構 PDF 結構。由於所有處理皆在使用者本機端完成，**檔案絕對不會上傳至任何後端伺服器**，能有效保障個人文件的資訊與隱私安全。

本工具提供「Before & After 雙欄對照預覽」排版，方便您在下載前直接對照浮水印移除前後的視覺效果。

## 💡 主要功能

工具目前提供以下六種常見 PDF 物件的掃描與清理選項：

1. **Form XObject 移除**：清除封裝在獨立子畫布中的常見文字或圖形浮水印（最常見）。
2. **註解移除 (Annots)**：移除蓋在文件最上層的 PDF 註解、標記或印章 (Stamp)。
3. **內容流掃描 (Direct Content)**：偵測並清空直接嵌入在頁面內容流中的可疑浮水印文字。
4. **ExtGState 狀態清理**：清理半透明浮水印所綁定的擴充圖形狀態設定。
5. **圖層清理 (OCG)**：隱藏或移除位於特定「隱形圖層」中的浮水印物件。
6. **圖片移除 (Image XObject)**：自動偵測並清空命名包含 `watermark` 或 `wm` 的圖片型態浮水印。

## 🚀 快速開始 (SPA 優勢)

本專案已完全重構為**「單一檔案單頁應用程式 (Single-File SPA)」**。所有的 CSS 樣式、JavaScript 業務邏輯及繁體中文詳細註解，皆已完美內聚在最上層的 `index.html` 中！

這意味著您擁有極致的**可攜性**與**離線可用性**：

### 📥 離線使用方式
1. **直接開啟**：直接在您的檔案總管中雙擊 `index.html`，即可在任何現代瀏覽器（Chrome, Edge, Firefox, Safari 等）中 100% 離線執行所有浮水印移除動作，完全不需要配置任何 HTTP 伺服器。
2. **隨身帶著走**：您可以將此單一 HTML 檔案發送給同事或儲存在隨身碟中，在沒有網路的極端環境下依舊能完美運作。

### 🌐 本地開發與靜態伺服器 (選用)
如果您希望在本地開發或測試，依舊可以使用 Python 內建的 HTTP 伺服器啟動：
```bash
# 在專案根目錄下執行
python3 -m http.server 8080
```
接著在瀏覽器中輸入 `http://localhost:8080` 即可。
